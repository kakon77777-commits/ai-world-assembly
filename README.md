# AI World Assembly

Internal integration workspace for the AI-Native Game / World Assembly architecture.

The repository is intentionally an integration layer rather than a replacement for SEDB or CompilableWorld.

Initial direction:

- versioned cross-system contracts;
- SEDB read adapters;
- CSC-OCM composition resolution;
- Dynamic Asset Graph reference implementation;
- CompilableWorld intake adapters;
- Three.js-first vertical slice;
- bounded AI World Assembler workflows.

Status: bootstrap in progress.
